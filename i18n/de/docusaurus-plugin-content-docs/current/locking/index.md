# Was sich sperren lässt {/* #what-you-can-lock */}

Eine Stage hat eine Liste pro Art von Inhalt. Die Art entscheidet, in welches Feld der Eintrag gehört,
in welchem Modus er funktioniert und worauf ein Spieler stößt, wenn er es trotzdem versucht. Die Form ist
aber immer gleich: eine Liste in einer Stage, und alles darin ist unerreichbar, bis die Stage offen ist.

Jede davon lässt sich auch auf einzelne Interaktionen eingrenzen statt auf alle: das Schwert tragen,
aber nicht schwingen, den Barren herstellen, aber die Rüstung nicht anziehen. →
[Unlock Actions](/wiki/locking/items-and-recipes/unlock-actions)

## Zwei Dinge, die du vorher wissen solltest {/* #two-things-worth-knowing-before-you-pick */}

**Die Stage-Art entscheidet mehr, als man denkt.** Manche Arten funktionieren nur serverweit, manche
nur pro Spieler; eine Sperre in der falschen Stage-Art wird still übersprungen und im Lade-Bericht
gemeldet. Die ganze Tabelle steht auf
[Globale vs. individuelle Stages](/wiki/start-here/global-vs-individual#what-can-each-one-lock).

**Der Editor ist der normale Weg, all das zu schreiben.** Jede Seite nennt den Reiter, auf dem es
liegt, und was sein Rechtsklick-Menü anbietet, weil dort ein Modpack tatsächlich gebaut wird. →
[Editor im Spiel](/wiki/in-game-tools/in-game-editor)
