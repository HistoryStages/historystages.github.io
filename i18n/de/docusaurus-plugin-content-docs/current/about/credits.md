# Credits {/* #credits */}

History Stages wird von **Flix100000** (Entwicklung) und **PixlStudios** (Grafik) gebaut.

Alle anderen, die geholfen haben, stehen in
**[CONTRIBUTORS.md](https://github.com/Flix100000/History-Stages/blob/neoforge-1.21.X/CONTRIBUTORS.md)**:
Code-Beiträge, Übersetzer und die Leute, deren Fehlerberichte und Kompatibilitäts-Funde die Mod geprägt
haben, ohne dass eine Zeile Code den Besitzer gewechselt hat.

Übersetzungen über Deutsch und Englisch hinaus kommen aus der Community: Russisch und seit 6.0.2
vereinfachtes Chinesisch. Sie entstehen auf **[Crowdin](https://crowdin.com/project/history-stages)**,
im Browser, ohne JSON-Dateien und ohne Pull Request. Neue Texte tauchen dort nach jedem Update von selbst
auf. Eine Sprache, die es auf Crowdin noch nicht gibt, kann man anfragen oder als Datei einschicken; der
[Abschnitt zu Übersetzungen in CONTRIBUTING.md](https://github.com/Flix100000/History-Stages/blob/neoforge-1.21.X/CONTRIBUTING.md#translations)
erklärt beides. Deutsch und Englisch werden im Repository aktuell gehalten. Übersetzer werden ebenfalls
in CONTRIBUTORS.md genannt.

## Mitmachen {/* #contributing */}

Pull Requests laufen über [GitHub](https://github.com/Flix100000/History-Stages); Fehlerberichte und
Wünsche sind dort oder auf [Discord](https://discord.gg/BeZzxyZ9c4) willkommen. →
[Hilfe & Fehler melden](/wiki/about/getting-help)

[CONTRIBUTING.md](https://github.com/Flix100000/History-Stages/blob/neoforge-1.21.X/CONTRIBUTING.md)
hat die Bauanleitung, den Code-Stil und die Bedingungen für Beiträge.

Die Dokumentation liegt in einem eigenen Repository,
[historystages.github.io](https://github.com/HistoryStages/historystages.github.io). Jede Seite hat unten
einen Link „Diese Seite bearbeiten“.
